# JavaScript - Fundamentos, Condições, Laços e Arrays

## Sobre o projeto

Esta repositório foi desenvolvido durante a aula da disciplina de **Back-End**, utilizando **JavaScript** e **Node.js**.

O objetivo é consolidar os conceitos fundamentais da linguagem por meio de exemplos práticos e exercícos, desenvolvendo a lógica de programação necessária para a construção de aplicações back-end.

---
## Objetivos

Ao concluir este projeto, o aluno será capaz de 

- Criar algoritmos utilizando JavaScript;
- Declarar e utilizar variáveis;
- Trabalhar com diferentes tipos de dados;
- Utilizar operadores aritméticos, relacionais e lógicos;
- Desenvolver as estruturaS condicionais;
- Utilizar estruturas de repetição;
- Manipular Arrays;
- Resolver problemas utilizando lógica de programação;
- Executar aplicações JavaScript utilizando o Node.js.
